3. The Box Model: content-box vs. border-box & overflow

content-box (Default)
Declared width: 200px
Visible box: 240px (200 + 30 pad + 10 border)
border-box
Declared width: 200px
Visible box: 200px (includes padding & border!)

Overflow Property (when fixed height is smaller than text content)

overflow: hidden;
Every CSS rule begins with a selector. Extra text that exceeds the 75px height is clipped and hidden from view.
overflow: scroll;
Every CSS rule begins with a selector. Scrollbars are always added so you can scroll to read the overflowing text.
overflow: auto;
Every CSS rule begins with a selector. Scrollbars appear automatically only on the axis that overflows.
