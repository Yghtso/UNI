3. Floating Elements (float: left; with Explicit Width & Clearfix)

When an element is floated left or right, it is shifted to the edge of its containing block and inline text reflows around it. Remember that a floated block element must have an explicit width, otherwise its width defaults to auto (100% of the parent container).
